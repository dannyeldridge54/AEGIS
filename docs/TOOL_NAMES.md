# AEGIS calculator names (Danny, 17 Nov 2026: "what's fitting to the jobs")
The Janus pair: two faces, one looking back to the first instant, one at the sky we observe now.
- **Chronos Clock** — the early-universe / string calculator (was "Janus String Calculator", tools/janus_calc). Its job is time: it clocks inflation in e-folds, finds N* from the reheating history, and runs the exact Mukhanov–Sasaki evolution.
- **Kairos Cosmos** — the late-universe and astrophysics calculator (was "Janus-LT", tools/janus_lt, plus "Janus-Astro", tools/janus_astro, as its astrophysics module). Its job is the cosmos at the moment we observe it: distances, BAO, supernovae, growth, stars, compact objects, gravitational waves, halos and dark matter.
Not to be confused with the SERAPIS model faces Kairos (untilted) and Chronos (tilted) in the papers.
Directories and import names are unchanged (no code breaks). The published Zenodo/GitHub records keep "Janus String Calculator" until the next release, which needs Danny's "Publish".
