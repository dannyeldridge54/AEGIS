# AEGIS calculator names (Danny, 17 Nov 2026: Chronos & Hyperion — time and light, Titan brothers)
- **Chronos Clock** — the early-universe / string calculator (was "Janus String Calculator", tools/janus_calc). Chronos, god of time: it clocks inflation in e-folds, finds N* from the reheating history, and runs the exact Mukhanov–Sasaki evolution.
- **Hyperion** — the late-universe and astrophysics calculator (was "Janus-LT", tools/janus_lt, plus "Janus-Astro", tools/janus_astro, as its astrophysics module). Hyperion, Titan of heavenly light and "the watcher from above": it reads the light of the sky we observe now — distances, BAO, supernovae, growth, stars, compact objects, gravitational waves, halos and dark matter.
"Janus" remains the family idea: two faces, one looking back to the first instant (Chronos Clock), one at the sky now (Hyperion).
Note: the SERAPIS model faces in the papers are also called Kairos (untilted) and Chronos (tilted); the tool is always "Chronos Clock" to keep them apart.
Directories and import names are unchanged (no code breaks). Published Zenodo/GitHub records keep "Janus String Calculator" until the next release, which needs Danny's "Publish".
