# Nuclear data (DATA, not committed; fetch with fetch.sh)
- h5/: ENDF/B-VIII.0 processed by NJOY into OpenMC HDF5 (temperatures 0K, 250K, 294K, 600K, 900K, 1200K, 2500K),
  from https://github.com/openmc-data-storage/ENDF-B-VIII.0-NNDC (h5_files/neutron/<Nuclide>.h5).
- endf/: raw ENDF-6 tapes from https://github.com/njoy/NJOY2016 tests/resources (ENDF/B-VIII.0 and others as named).
