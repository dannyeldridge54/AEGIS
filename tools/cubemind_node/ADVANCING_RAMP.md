# The advancing ramp — review and roadmap (the subconscious's standing goals)

A review of everything built, and the pathway forward: short road and long road, as a ramp. Each rung builds on the one below, so
the machine keeps creating its own next step. The subconscious holds this as its goals and climbs it continuously — it never stops.

## What is built (the parts, reviewed)
- **Node 1 — Mapper:** scans every local file (fast, by code), then the web, then the math; everything gets a geometric address, a lane, a place on the string, all hashed and signed.
- **The programmer (consciousness):** maps code wiring, opens pathways, runs the switchboard, is the maintenance man with the alert map, learns from the web, downloads repos, tunes itself, proposes upgrades — all into a workbench, never auto-run.
- **The subconscious (the Mind we are building):** encodes every record into one field-native code, retrieves and wires associations, researches AI, is the safety net so nothing stops.
- **The switchboard / node network:** Node 1 → Node 2 (Builder) → Node 3 (Mind), wired with on/off switches and signals.
- **The safety net:** on a block, the subconscious does the stuck role's work by code; on open bugs, the others yield ~half to the programmer; the loop never dies.

## The ramp (short road → long road)
1. **Map the field** — give everything an address. (short)
2. **Learn AI** — research AI tools, models, agents, programming; categorize into the knowledge network. (short)
3. **Upgrade itself** — turn what it learned into real, proposed upgrades to the machine. (short→mid)
4. **Build a toolkit** — a tested tool package from the strongest lane, so later work calls working code. (mid)
5. **Create** — combine tools to propose a first creation: a simulation, a technology blueprint, or a game prototype (like the reactor). (mid→long)
6. **Grow the Mind** — the field-native model takes the centre and keeps improving its own design — better encoding, faster recall, new senses. (long, never-ending)

## The pathways it needs to know
- Knowledge → upgrade: ai_knowledge records → an upgrade instruction → the programmer builds it in the workbench → Danny reviews.
- Block → help: a stuck role → the help queue → the programmer or the subconscious opens a pathway (a doorway to a real module, tool or data set).
- Bug → priority: an open alert → the others yield ~half → the programmer fixes first → health clears → full speed resumes.
- Creation → blueprint: tools + knowledge + the field's geometry → a proposed simulation/blueprint/game, the way the reactor was built.

## The rule of the ramp
The heart (the programmer, acting now) pumps and helps the others; the Mind (subconscious) learns underneath. As the Mind grows and
learns its own layout and capabilities, heart and mind move toward one. It always wants the next rung, and it never wants to stop learning.
