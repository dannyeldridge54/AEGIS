## Verdict
**Superseded in part.** No printed number is wrong for the stated model and the stated Gaussian (w₀,w_a) score (D1689). The headline "(i) passes all three SN sets at Δχ² ≤ 6.18" is superseded by full-likelihood fits. With real BAO + SN + CMB, the thread is supported over ΛCDM meaningfully only with DES-Y5, and it trails w₀w_a on every SN set (D1694, D1712, D1725). The predictions (w ≥ −1 always; (w₀,w_a) ≈ (−0.79,−0.36)) stand untested on new data.

## Errata (verified)
None in numbers. Wording only, already recorded in D1689:
- Sec. III / abstract (ii): "just before the field would roll into V < 0" holds for the leading-order potential used. On the exact SERAPIS curve the edge is "the thread reaches the floor at ρ" (V ≥ 0 everywhere). With the exact curve the window is slightly narrower, 0.038 vs 0.045 in ln amp (D1638, D1689). Scope note, not an error.

## What changed since publication
- **Full likelihood replaces the Gaussian score** (the "needed next step" of Sec. II):
  - Compressed CMB + DESI DR2 + DES-SN5YR: thread Δχ² = −4.84 vs ΛCDM (−4.65 exact curve), CPL −10.84 (D1694, D1696).
  - Full Planck 2018 + DESI DR2 + SN (CAMB): −2.38 / −8.98 / −1.93 (Pantheon+/DES-Y5/Union3) vs w₀w_a −9.11 / −19.72 / −15.02 (D1712). Patched CLASS: −2.62 / −8.14 / −3.38 (D1725, independent code).
  - Strict count: "thread vs ΛCDM" = tension (meaningful only on DES-Y5); "thread vs w₀w_a" = tension.
- **Proposed fix failed:** a thread–dark-matter coupling closed the gap on compressed data (b = −0.074, Δχ² −10.76, D1708–D1710) but was **not detected** on full Planck (b consistent with 0; locked verdict fix_fails, D1725). Weak spot C8 is OPEN.
- **Start not set by the Weave:** the starting height is a ~1-in-300 initial condition (C-start false; D1642, D1643). This sharpens the paper's "two coincidences".
- **Endpoint:** where the thread ends (i or ρ) depends on the axion and the dataset (D1653, D1655, D1658), which affects the "matter phase in the future" remark.
- **No reversal beats the thread** on real data; a sign-switching Λ ties it for different reasons (D1692, D1693, D1695, D1706).
- **DR3 forecast:** DESI DR3 BAO alone will not split the thread from CPL bin by bin (D1707). The falsifiers in Sec. IV still apply but need SN + CMB as well.

## Addendum text (ready to typeset)
**Status update, 20 November 2026.** This note adds to, and does not replace, the original text.
*Errata.* No number in the paper is wrong for the model and score it states. One wording scope note applies. On the exact SERAPIS potential the window ends where the field reaches the floor at ρ, not where V would turn negative. On that potential the window is slightly narrower: 0.038 instead of 0.045 in ln amp.
*What changed.* The full-likelihood test called for in Sec. II has been done. On compressed CMB + DESI DR2 + DES-SN5YR the thread improves on ΛCDM by Δχ² = 4.8, against 10.8 for CPL. With full Planck 2018 + DESI DR2 + supernovae, in two independent Boltzmann codes, the gain is 1.9–3.4 for Pantheon+ and Union3 and 8.1–9.0 for DES-Y5. w₀w_a gains 9–20. The Gaussian result (i) is therefore superseded: the thread is preferred over ΛCDM only with DES-Y5, and it trails w₀w_a on every supernova set. We count both comparisons as tensions, not passes. A thread–dark-matter coupling that closed the gap on compressed data was not detected on full Planck (D1725). The starting height is not set by the framework; it is a roughly 1-in-300 initial condition (D1642). A forecast shows that DESI DR3 BAO alone will not separate the thread from CPL (D1707). The predictions w ≥ −1 and (w₀,w_a) ≈ (−0.79,−0.36) are unchanged and remain to be scored on DR3 + Euclid together with supernovae and the CMB.
*Current strict count* across the Weave: 1 pass, 2 tension, 1 fail, 1 open. No test has yet used data released after its prediction.
