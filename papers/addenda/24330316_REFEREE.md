## Errata (verified)
1. **CMB comparison values (Sec. "The audited predictions").** The paper uses CMB-SPA 0.9684±0.0030 and CMB-SPA+DESI 0.9728±0.0027. This pair is not in any publication. Published values: SPT-3G D1 0.9679±0.0033; Balkenhol+ 2512.10613 0.9682±0.0032 (+DESI 0.9728±0.0029); McDonough–Ferreira 2512.05108 0.9693±0.0029 (+DESI 0.9737±0.0025). Corrected statement: the point is **+1.75 to +1.97σ** from CMB-SPA, not +2.0σ. The frozen-range band is +0.85 to +2.1σ from CMB-SPA and −0.78 to +0.74σ from CMB-SPA+DESI. The tension belongs to the benchmark point, not the model. Source: D1273a; field_tests/results/serapis_point_vs_data_2026-11-18.txt, audit_2026-11-18.txt.
2. **String meter (Sec. "The CMB as a string meter").** "±14%" used ∂n_s/∂ln C = 1.171e-2. That slope was measured at the wave baseline C = 1.15e-6 but applied at the benchmark C = 1.249e-6. The slope at the benchmark is **0.0133**, so the meter is **±12%** (±6% if σ(n_s) = 0.0016 is read as a 95% half-width). The ±19% (LiteBIRD) figure used the same slope and is affected in the same direction; it was not recomputed. Source: D1265a, D1265b; field_tests/results/ns_response_slope_check_2026-11-18.txt.
3. **"Leptogenesis-fixed" (abstract).** T_R is fixed by the *choice* M_H = 1e12 GeV. The benchmark's own instanton mass, M_H = 9.8e10 GeV, gives T_R ≈ 7e7 GeV and no thermal leptogenesis (Y_B about ×12 short). The point would then move to N* 49.41, n_s 0.97362, still inside the frozen band. Source: D1270; field_tests/results/pw7_instanton_MH.txt.
