## What changed since
- **Rule 1 lapse, disclosed (PREREG_Q7_SPLIT_THREAD_DEVIATIONS D1, D1733):** the Q7 lock was committed locally (108ade6e) but the push failed before the script ran, so the lock was not public at run time. The hash verifies, it was pushed straight after, and there was no rerun. The paper says locks are "committed and pushed … before the script runs"; this is the first recorded exception.
- **Deviations files in use:** 139 *_DEVIATIONS.md files against ~840 locks (field_tests/rules, 20 Nov), compared with 2 on 16 Nov. They now also record referee-driven tightening (Evidence Atlas D1–D3) and convergence fixes (PREREG_PLANCK_CLASS D1, D1724–D1725).
- **Evidence Atlas strict rule (D1–D3):** a pass counts as evidence only if it is a headline prediction that is not post hoc and not inherited. Rows are tagged by timing (future-data / locked / post-hoc) and kind (match / bound / comparison). Comparisons need ΔAIC < −2, and an 'open' row never counts. D3 fixed a code bug that counted an open row. Result: 1 pass (r bound), 2 tension, 1 fail (D1725), 1 open, and **no test yet used data released after its prediction**. Rule 5 ("scored only on later data") has therefore not yet been exercised.
- **New worked examples:** a stop rule honoured with a NULL (D1723); a nested-model check catching non-convergence, since a model containing ΛCDM cannot score worse than it (D1724); a locked verdict kept as a fail (D1725); an "8σ" claim withdrawn as non-physical once coefficient spread was included (D1743).

## Addendum text
Status update, 20 November 2026. No errata were found. Four lessons since publication. (1) The first recorded lapse of rule 1: one lock (Q7, quark sector) was committed but, because a push failed, was not yet public when its script ran. The hash verifies and there was no rerun. It is disclosed in a deviations file. Pushing must be confirmed before running, not assumed. (2) Deviations files are now routine: 139 against about 840 locks. They also record changes that make a rule stricter after review. (3) Counting evidence needs its own locked rule. The project's evidence atlas now counts only headline predictions that are neither post hoc nor inherited from standard physics. It tags each row by timing and kind, and requires ΔAIC < −2 for model comparisons. A referee found a bug in the code that applied this rule (an "open" row was counted), so counting code needs tests too. The strict tally is 1 pass, 2 tensions, 1 failure and 1 open item. No test has yet used data released after its prediction, so "freeze and wait" is still waiting. (4) Further worked examples: a stop rule ending in a null result (D1723), a nested-model check that exposed an unconverged fit (D1724), a locked failure kept as a failure (D1725), and a significance claim withdrawn once model spread was included (D1743). See Weave Control and the Evidence Atlas (this deposit series, 20 Nov 2026).
