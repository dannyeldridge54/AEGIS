Status update, 20 November 2026

Addendum to: A Start-Condition Ripple in Exact Mukhanov–Sasaki Running, and a Cheap Fix (Zenodo record 24330318) · Danny Eldridge, independent researcher, Oklahoma City, Oklahoma, USA · dannyeldridge54@gmail.com

Status update, 20 November 2026. No errors have been found. The recommended recheck of older α_s values has been done for the SERAPIS branches. At τ = i the ripple-free value differs by about 7×10⁻⁷ (D1343). No earlier accuracy verdict changes (D1346). The fixed procedure (start at k/aH = 4000, nine-point fit over ±0.1 in ln k) is now the reference engine for all later exact spectra. These include the species-plateau inflation results, n_s = 0.97065 (fitted), r = 5.41×10⁻⁴, α_s = −9.68×10⁻⁴ ("Inflation from the Running of the Species Scale", doi:10.5281/zenodo.24378141). A fast engine agrees with it to ≤ 8×10⁻⁷ in n_s (D1542). A related lesson came later: a narrow finite difference of the potential produced similar noise in α_s. It was fixed with a five-point stencil before the run was accepted (D1523). The overall status of the model is in the SERAPIS v3.4 status update (doi:10.5281/zenodo.24396665).
