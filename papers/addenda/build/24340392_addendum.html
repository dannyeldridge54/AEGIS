Status update, 20 November 2026

Addendum to: Janus String Calculator 1.3 (Zenodo record 24340392) · Danny Eldridge, independent researcher, Oklahoma City, Oklahoma, USA · dannyeldridge54@gmail.com

Status update, 20 November 2026. No errors were found in version 1.3. Its validation claims match the locked tests shipped with it. One caveat is added: the n_s and r battery (PREREG_D990) used the exact solver's older start setting (bd = 200), whose small ripple affects α_s, not n_s or r, so that battery's verdict stands. The α_s battery used the safer setting. Since release, a model library and a sourced table of current CMB constraints (Planck, ACT DR6, SPT-3G and combinations; BICEP/Keck limits on r) have been added to the development tree; they will ship in a later version. Users should note that the SERAPIS-E tools bundled here describe an earlier stage of the model. The project's current inflation model is the species-scale plateau, Inflation from the Running of the Species Scale (doi:10.5281/zenodo.24378141). In that model the spectral index is fitted, not predicted. Its current status is summarised in the SERAPIS v3.4 status update (doi:10.5281/zenodo.24396665).
