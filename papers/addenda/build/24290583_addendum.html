Addendum to: A Parameter-Free Consistency Relation for Plateau Inflation with an Uplift Ramp (Zenodo record 24290583) · Danny Eldridge, independent researcher, Oklahoma City, Oklahoma, USA · dannyeldridge54@gmail.com

Status update, 20 November 2026. One correction. The letter assigns the SERAPIS modular plateaus the class (p, κ) = (2√2, ½). That holds for the original, fitted tilt only. For the SERAPIS-E realisation, whose one-loop tilt grows as E(τ,2) ∝ e^{+2√2φ}, the class is (p, κ) = (2√2, 1). There the leading-order relation underestimates the exact running by 3.3–4.0%, not about 1% (D1234). So the example value α_s = −8.1×10⁻⁴ refers to the original tilt. With κ = 1 the same (n_s, r) give about −1.0×10⁻³. The relation itself, its β_s companion and the T-model checks are unaffected. Two later results narrow its use. The parameter κ does not separate a model's two vacua (audit, doi:10.5281/zenodo.24330316). And at LiteBIRD's stated requirement δr = 10⁻³, r ≈ 5×10⁻⁴ is a 0.5σ effect, so it is "within reach" only if LiteBIRD beats that requirement about tenfold (D1440). The exact-spectrum method used for the accuracy checks is described in doi:10.5281/zenodo.24330318. The model this letter served is now reported in "Inflation from the Running of the Species Scale" (doi:10.5281/zenodo.24378141) and the SERAPIS v3.4 status update (doi:10.5281/zenodo.24396665). Its genuine predictions are r and α_s; n_s is fitted.
