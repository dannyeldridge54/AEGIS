# DRAFT — short notes for experiment teams (one paragraph each). NOT SENT.
Use only after the arXiv posting exists; link the paper, never attach unpublished files unasked.

**CMB (Simons Observatory / LiteBIRD contacts):** SERAPIS predicts r = (4.6–5.7)×10⁻⁴ with n_s ≈ 0.970–0.975 and α_s ≈ −9×10⁻⁴, plus a parameter-free relation α_s(n_s, r) (Janus-pair section). It is a benchmark below current and planned sensitivity: any detection of r ≳ 10⁻³ rules it out; confirming r ≈ 5×10⁻⁴ needs σ(r) ~ 10⁻⁴.

**Neutrino mass (DESI / Euclid):** The baryogenesis estimate (Affleck–Dine LH_u, order of magnitude) requires m_ν1 ≲ 10⁻⁸ eV, so Σm_ν ≈ 0.059 eV if the ordering is normal — right at the current DESI DR2 bound. Σm_ν > 0.07 eV would rule out this baryogenesis route.

**Oscillation (JUNO / DUNE):** The model takes normal ordering from data; it does not predict the ordering.
