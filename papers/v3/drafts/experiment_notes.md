# DRAFT — short notes for experiment teams (one paragraph each). NOT SENT.
Use only after the arXiv posting exists; link the paper, never attach unpublished files unasked.

**CMB (Simons Observatory / LiteBIRD / CMB-S4 contacts):** SERAPIS predicts r = (4.6–5.7)×10⁻⁴ with n_s ≈ 0.970–0.975 and α_s ≈ −9×10⁻⁴, plus a parameter-free relation α_s(n_s, r) (Janus-pair section). It is a useful benchmark just below current sensitivity: a non-detection at σ(r) ~ 10⁻³ is consistent; r < 2.3×10⁻⁴ (95%) would rule it out.

**Neutrino mass (DESI / Euclid):** The baryogenesis route (Affleck–Dine LH_u) requires m_ν1 ≲ 10⁻⁸ eV, so Σm_ν ≈ 0.059 eV with normal ordering — right at the current DESI DR2 bound. Σm_ν > 0.07 eV or inverted ordering would rule it out.

**Oscillation (JUNO / DUNE):** Normal ordering is required; inverted ordering at > 3σ excludes the model.
