# SERAPIS v3.3 draft — changes from v3.2 (10.5281/zenodo.24289118)
Draft only; not uploaded. Source: papers/v3/serapis_v3.3_draft.tex (v3.2 file unchanged). 18 pages.
- D657a: proton-stability paragraph: "as expected for a non-R symmetry" was wrong; an anomaly-free non-R symmetry forbidding the dangerous operators exists (proton hexality, a Z₆; 1102.3595), but the modular centre cannot supply a Z₆, and non-R symmetries cannot also solve the μ problem. Our computed null result (D656, D657) is unchanged.
- Table I column widths adjusted (layout only).
- D925–D937: new limitations paragraph "Which modulus can roll": p = k√(2/n) selects a T² complex-structure modulus (n = 1) unless a log-corrected approach is tuned (D929, D937); one-modulus CY directions give α = 1 (D928); mirror-quintic prior art (1605.03974, D927); on T⁶/(Z₂×Z₂) no flux leaves a single U flat: identically excluded by the tadpole (D933), point-wise not found numerically for 0.2 ≤ Im ≤ 5 (D934, D935); existing flat directions are diagonal and give sibling attractors (2209.02720, D932, D936). Two references added.
- D941–D948: caveat on the plateau's origin extended: a candidate origin (heavy field χ integrated out, V = AB/(A+B); one-loop image mass ∝ E(τ,2) from a 6D boson loop on R⁴ × T²; locked two-field check |Δn_s| ≤ 2e-5, |Δr/r| ≤ 0.05% for M ≤ 0.2; evades the D709/D712 obstructions); assumptions stated (small tree mass of χ, 6D loop field, fixed T² area); not built in a string compactification.
- D950: Project H caveat sharpened: the 6D loop tower must be non-supersymmetric at the T² scale; soft SUSY breaking gives weight s = 1 (log(U₂|η|⁴), N=2 threshold form, 0805.1874) → p = √2, α = 1/3. One reference added.
- D953–D962: independent reproduction with separately written code (tools/serapis_calc, selftest incl. exact power-law and j-invariant checks): n_s and r reproduced on all three branches (SERAPIS-E D953, Chronos/Kairos D959, SERAPIS-ρ D962); α_s reproduced to ~10%, with a Bunch–Davies start sensitivity found in both codes (D958) and a convergence test pending (D960). To state in v3.3's reproducibility section.
- D963: Project H caveat: the sign of the one-loop mass is an open condition (Wilson-line scalars get a negative mass in hep-ph/0004091); reference added.
- D963–D968: Project H caveat rewritten: sign by coupling type (Wilson line/Yukawa negative, gauge-charged localised positive), E(U,2)/A² from the T² gauge-loop sum without light gauginos (ADS anti-D5 sector), gauge-invariant pinning by mixing with a vev below the T² KK scale; two references added.
- D976–D978: Project H caveat: with λ′ ≤ 1/E(ρ,2), the largest allowed λ′ ≈ 0.17 with the consistent tilt C = λ′C₀ (locked refit) gives a sibling model, n_s ≈ 0.9714, r ≈ 5.0e-4 (Δn_s = −2.7e-3, Δr/r = +8.5% at fixed reheating), still inside the frozen band; fixed C gives ≈41 e-folds and is excluded.
- D985: Project H caveat: string-level check (Level S3, locked): the anti-D5 position scalar's one-loop mass² from the Möbius amplitude with the full tower is positive with E(U,2)/A² shape (to 1% for A ≳ (10√α′)²); the sign condition is met at string level in the ADS sector; other conditions remain open.
- D987–D988: Project H caveat: the χ mass's shape-independent local part is string-scale and tadpole-dominated (sign oscillates in the closed-string region); positive → absorbed into λ′, negative → fatal; needs dilaton backreaction.
- D979, D981/D990: reproducibility section gains an "Independent reproduction" paragraph: N* offset +0.171 (end-of-inflation definition; Δn_s = +1.5e-4, D979); α_s convergence test passed (−9.88e-4 SERAPIS-E, −9.94e-4 Chronos, stable to 0.2%, inside published bands; D990). Replaces the 'convergence test pending' wording of the D953–D962 entry.

- (17 Nov, D1013) Prediction sheet: widen SERAPIS-ρ α_s band upper edge from −9.5e-4 to −9.9e-4 at N* ≈ 46 (exact wide-grid −9.863e-4); no change of prediction.
