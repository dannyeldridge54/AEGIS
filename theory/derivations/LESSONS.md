# Loop lessons (read FIRST every tick; append after every tick's DERIVE step)
Each line: date, D-number, the lesson, and how it changes the next steps. Keep it short; condense when it grows past ~60 lines.

- 2026-11-15 D720/D724/D725: eigen- or Takagi methods fail on degenerate or nilpotent blocks. Use a symmetric square root, and check residuals before trusting a coupling.
- 2026-11-15 D727: opposite-sign mass eigenvalues give an axion-like coupling 2sθ′. Never assume λ ∝ ΔM.
- 2026-11-15 D728→D738: check the assumed ratio ranges (ΔM/M) against the model's own output before calling something a "natural" pass.
- 2026-11-15 D759: nested finite differences make n_s noisy. Use analytic or mpmath derivatives, and check C = 0 against the earlier untilted result.
- 2026-11-15 D760: a fetched paper's species function was log η (F₁), not E(τ,2). Check which modular function a source actually uses before building on it.
- 2026-11-16 D762: check whether a vacuum or trajectory sits on a CP-conserving locus (imaginary axis, Re τ = ±½, the unit arc) before claiming any CP-violating result. Our two vacua and the inflaton line all do, so every CP effect needs an explicit phase source.
- 2026-11-16 D762: a PASS that leaves a parameter "unspecified" (here δ) hides an assumption. Make it a postulate at once, so the derived:assumed count stays honest.
- 2026-11-16 D763: before claiming a low-energy prediction from a high-energy mechanism, check whether the low-energy parameter cancels out of the formula (here U drops out of H = Y†Y). Run a real-parameter control grid as the K4 regression.
- 2026-11-16 D763: write a postulate's falsifier as "what result would favour the ALTERNATIVE". It is sharper than "what would disfavour the postulate".
- 2026-11-16 D764: "j(τ) real ⇔ CP-conserving" is a one-line, modular-invariant CP test. Use it instead of basis-dependent coupling phases.
- 2026-11-16 D764: when a mechanism ties a new field to the inflaton (here U₂ = c/U₁), check at once whether it changes the inflaton's kinetic term. Queue a forward check before trusting the old n_s and r.
- 2026-11-16 D765: an imported vacuum relation that involves the inflaton changes the kinetic term, here doubling the Kähler metric and r. Check every new constraint against the inflaton direction before using it for other sectors.
- 2026-11-16 D765: when reusing a solver under a new field map, grep it for hard-coded maps (s2, start values) and write the DEVIATIONS before the first run, not after a crash.
- 2026-11-16 D766: every new flux or brane ingredient must be booked against the tadpole (32 = n_flux + 2n_D3 + n_O3′) the moment it is proposed. Here it forced 5/5/5+1 → 3/3/3+1.
- 2026-11-16 D766: a frozen map node can't be changed by a MAP line, by design. A label slip on a frozen node needs a manual, documented edit, which is what D765a did.
- 2026-11-16 D767: rescale from the actual formula, not from a summary range. D766 scaled a union range by N and missed that the tilt depends on N − N0. The forward DERIVE step caught it, which is the design working.
- 2026-11-16 D768: when every derivation route is closed, check how the leading published models handle the same gap. If they also choose the function (e.g. a nilpotent metric), the honest status is "postulated at the field's standard". Record what still distinguishes us (here r is ~4.5× lower).
- 2026-11-16 D769: a lock's success criterion must test the physical question at the right moment. "Ends in the valley" had to be judged after reheating-era relaxation, not at ε = 1. When writing a PREREG, state WHEN each quantity is evaluated.
- 2026-11-16 D769: write the plateau in the exact form the solver uses. The shorthand 1 − E(ρ)/E and the code's Ê/(Ê + 1) give the same n_s and r but different N(y) (D769 run 1 was invalid for this reason).
- 2026-11-16 D770: in modular field spaces, judge "where it settled" after reducing to the fundamental domain. A raw final point like ½ + 0.29i is ρ in disguise.
- 2026-11-16 D771: when a source says an ingredient "requires" another (odd flux ⇒ exotic planes), book the second ingredient in the same tick. D766 missed the O3′ cost and needed D766b.
- 2026-11-16 D772: before adopting a published vacuum, read its FULL flux vector and every relation it imposes (here τ₃ = S was hidden behind "τ₁τ₂ = b₃/a⁰"). One partial read cost three ticks (D764–D771).
- 2026-11-16 D773: before searching numerically for a vacuum, check whether the equations force a parameter real (here a double root of a real quadratic). A one-line analytic argument replaced 5.8e6 sympy solves and settled the general case.
- 2026-11-16 D762→D773: a candidate mechanism (flux CP) took five ticks to retire. Next time, test a mechanism's compatibility with the INFLATON first, the cheapest fatal check.
- 2026-11-16 D774: when a chain of reverse ticks keeps retiring mechanisms, declare the chain exhausted, keep the explicit postulate, and switch the next forward tick to UPGRADING an estimate into a computation. That adds more than another speculative source.
- 2026-11-16 D775: the Davidson–Ibarra bound is saturated only for hierarchical spectra with the decaying state LIGHTEST. When the decaying state's loop partners are lighter (x < 1), the true ε can be 30× smaller. Compute ε before calling leptogenesis a pass.
- 2026-11-16 D777: at a fixed point with a residual symmetry (Z₃ at ρ), a sector built from ONE aligned form inherits exact degeneracies. Check the spectrum's degeneracy pattern first, before scanning for fits.
- 2026-11-16 D778: at an exact fixed point, write down the residual-symmetry charges of every field FIRST. A two-line charge argument (q_i + q_j ≡ 0) would have predicted D741, D777 and D778 without any scans.
- 2026-11-16 D779: Casas–Ibarra assumes every heavy state couples to every lepton. Under a residual symmetry, check the allowed Yukawa slots before using it (it invalidated D775's set-up). Also: apply a DEVIATIONS fix with a careful edit; a sed replacement swallowed a statement (D2).
- 2026-11-16 D780: an inflaton oscillating about a fixed point carries the residual-symmetry charge. Its decay products are charged, so check that the lightest charged state can decay BEFORE trusting any reheating temperature. (D725 missed this, and D731–D776 were built on it.)
- 2026-11-16 D781: an N* shift of ~1.5 e-folds per 2 decades of T_R is enough to cross the frozen r band. Treat every change to the reheating history as a direct test of the frozen numbers, not a side issue.
- 2026-11-16 D783: include phase-space factors (192π³ for 3-body) in decay-scale estimates. They moved D782's Λ bound by a factor ~3, enough to change "comfortable" into "tight".
- 2026-11-16 D785: run every structural finding on one vacuum as a mirror test on the other (the plan's β2). The ρ Z₃ obstruction does NOT carry to i, and saying so with a computation keeps the τ = i branch's claims clean.
- 2026-11-16 D787: a residual discrete symmetry restricted to the SM often reduces to a familiar one (here baryon triality). Identify it; it imports known results (anomaly freedom, proton stability) for free.
- 2026-11-16 D788: check the Nanopoulos–Weinberg order counting BEFORE proposing any decay-baryogenesis route. A particle that is stable without the B-violating coupling needs two insertions, which kills higher-dimension routes at once.
- 2026-11-16 D789: after adding a mediator, assign B (and L) charges to every new field from its couplings and see whether B is still violated anywhere. A mediator can quietly make the decay B-conserving.
- 2026-11-16 D790: a charge read-out in modular field space must use the local coordinate of the image the field actually settled at. Reduce first, then compute the charge (the D770 lesson applied to velocities too).
- 2026-11-16 D791: isocurvature allowances must be taken from the data (β_iso ~ 0.04 of a 4.6e-5 amplitude), not set by hand as O(0.1). D790's hand allowance was off by ~4 orders of magnitude.
- 2026-11-16 D792: when two problems fail separately (too little dilution, too much asymmetry), try combining them. The late decay that "ruined" the frozen band is exactly the dilution the over-producing AD needed.
- 2026-11-16 D794: when mirroring a mechanism between vacua, check what the residual symmetry forces at QUADRATIC order (isotropy) and whether its charge is additive. Z₃ protects an orbit charge; Z₂ does neither.
- 2026-11-16 D795: a potential that depends only on |holomorphic function| inherits an accidental U(1) at leading order, so symmetry counting alone (Z₂ 'allows' anisotropy) can mislead. Also lock diagnostics in the canonical (local) coordinate: a τ-circle is not a z-circle.
- 2026-11-16 D796: before locking scaling predictions for angular modes, write the lowest invariant monomial for EACH mode (Re z⁶ → r⁴ relative, not r²). D796's c6 prediction failed on exactly this bookkeeping.
- 2026-11-16 D797: when a postulate fixes a function's PLACEMENT (numerator vs denominator, metric vs potential), check that the candidate source puts it there. The right function in the wrong slot gives the wrong shape (here E additive → hilltop, 1/E → plateau).
