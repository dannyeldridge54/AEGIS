# PREREG LHC12 — diagnose the ATLAS 36.1 fb⁻¹ residual (446.6 vs 460 GeV) (locked before computing)
Literature (arXiv:1712.02118, read 18 Nov): Table 2 electroweak event acceptance 0.09 (400 GeV, 0.2 ns) → 0.12 (600 GeV, 0.2 ns);
the 460 GeV limit is quoted at FIXED τ = 0.2 ns; decay-position window 122.5–295 mm; cross sections Prospino NLO.
Our recast held event acceptance constant, used our mass-dependent τ (0.2055 → 0.2025 ns, 400 → 460 GeV) and 299 mm.
Changes tested, each alone and all together (kinematic boost, D1307):
 (a) event acceptance linear in mass through the two Table 2 points; (b) τ fixed at 0.2 ns; (c) R_out = 295 mm.
## Predictions
- P1: (a) alone raises the limit by 5–10 GeV.
- P2: (b) and (c) each move it by < 3 GeV.
- P3: all three together give a limit within 1.5% of 460 GeV (453–467), and the ATLAS 136 fb⁻¹ recast with (a)'s analogue is NOT changed here (different search, no Table 2 used).
