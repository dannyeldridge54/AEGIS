# PREREG D2046: B0c route 3, a W₀ = 0 flux vacuum at the symmetric point S = ρ plus a D(−1)/E3 instanton term W_np = B·e^{2πikS} (locked before computing)
**Basis:** W = 0 flux vacua are common at enhanced-symmetry points (DeWolfe–Giryavets–Kachru–Taylor, hep-th/0411061). A non-perturbative S-dependent term then sets the effective W₀.

**Compute:** at S = ρ, Im S = √3/2, so |W_np| = |B|·e^{−π√3·k}. For integer k = 1…6, solve for the B that gives 5.6e-9.

**Look-elsewhere (lens 5):** take B natural if 0.1 ≤ |B| ≤ 10. Compute the probability that a log-uniform target lands in some k's natural window. That window covers ln 100 out of a spacing of π√3 per k.

**Verdict:**
- **FEASIBLE** if some integer k gives a natural B. Then B and k are recorded as knobs to derive: k from the instanton charge, B from the one-loop determinant.
- **FAIL** if no k does.
- **No evidence credit** if the look-elsewhere probability exceeds 0.3.
