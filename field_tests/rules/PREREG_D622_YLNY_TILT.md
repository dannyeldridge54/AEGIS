# PREREG D622: sensitivity of two-term SERAPIS to an HM-like y·ln y tilt (D621), locked before computing
Model: plateau I²/(I² + 1) + ε·T(τ), with T = I₁·ln(e + I₁)/ln(e + I₁(y₀)), normalised to equal I₁ at y₀ = 24.
- At the cusp this grows ∝ y·ln y (HM-like).
- Near i it equals I₁·(1 + O(I₁)), so it is quadratic. The |δ|²ln|δ|² refinement does not affect inflation and is not modelled.
Grid: ε ∈ {0.8e-4, 1.0e-4, 1.3e-4, 1.6e-4}; N* ∈ {46, 48, 50} (the D602 range).
Machinery: the D575/D602 slow-roll code, with the D588 offsets (Δn_s = −0.0003, Δy* = −0.4).
Report n_s, r, y* and the allowed set under the D602 rule (2σ vs SPA+DESI, y* ≤ 25).
Verdict: the predictions are ROBUST if the n_s/r band of the allowed set overlaps D605's band (n_s 0.970–0.975, r 4.8–5.7e-4) to within 0.002 in n_s and 20% in r.
