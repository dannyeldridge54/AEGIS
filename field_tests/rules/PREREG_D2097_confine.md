# PREREG D2097: hidden-sector confinement of the unified PS model's exotics. Locked before computing.

**Formulas:**
- **β:** He–Li–Sun 2112.09632 Eq. 3.12, quoted: β_i = −6 + 2|I_ai| + |I_bi| + |I_ci| for USp(N⁽ⁱ⁾) filler stacks. Our ring with N = 2 (2N⁽ⁱ⁾ counting via the 2^k tadpole factor) is USp(2) ≅ SU(2).
- **Couplings (D2083 rule):** α_x⁻¹(M_s) = K·Re z_x, with K = α_G⁻¹/Re z_vis. Inputs: α_G⁻¹ = 25.0 (two-loop, D2084), Re z_vis = 6, M_s = 1.0e16 GeV (D2084, M_SUSY = 3 TeV).
- **Confinement scale:** Λ_i = M_s exp(−2π α_i⁻¹(M_s)/|β_i|), for β_i < 0. This is the one-loop SUSY running, dα⁻¹/dlnμ = −β/2π with our sign (β < 0 means asymptotically free).

**Data:** all 6 completions of the unified model at χ = (1, 3, 2).

**Pass rule:** a completion PASSES iff **every** hidden ring that carries a chiral exotic has:
- β < 0, and
- 1e4 GeV ≤ Λ ≤ M_s (confines above 10 TeV, i.e. above the LHC-visible range).

**Verdict:** PASS if ≥ 1 completion passes; else FAIL.

**Not done (stated):** whether the composites are themselves vector-like or heavy (He–Li–Sun give no general rule), and two-loop hidden running.
