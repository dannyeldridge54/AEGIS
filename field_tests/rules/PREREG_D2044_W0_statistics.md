# PREREG D2044: can a Z₆-II orbifold flux vacuum give |W₀| = 5.6e-9 (v4)? This is the B4/B7 gate (landscape statistics, look-elsewhere lens 5)
**Rule:** Denef–Douglas / Ashok–Douglas statistics (hep-th/0307049, hep-th/0404116).
- Near W₀ = 0 the distribution of |W₀|² is uniform, so the fraction of vacua with |W₀| < ε is ≈ ε²/⟨|W₀|²⟩, with ⟨|W₀|²⟩ = O(1) in Planck units.
- Number of flux vacua: N_vac ≈ (2π L)^{b₃}/b₃! × O(1), with b₃ = 2h²¹ + 2 = 4 (h²¹ = 1, v4 / 2404.18995). L = tadpole budget; L = 12 (χ/4) is the generous value.
- Expected count with |W₀| ≤ 5.6e-9: N_hit = N_vac × (5.6e-9)².

**Verdict:**
- N_hit ≥ 1 → PASS (statistically reachable).
- N_hit < 1e-3 → **FAIL**: W₀ needs a mechanism (exactly W₀ = 0 at tree level plus a non-perturbative source, or a symmetry). Record that as a derivation target.
- Otherwise MARGINAL.
- The orientifold's actual tadpole sign problem (2404.18995) is reported alongside.
