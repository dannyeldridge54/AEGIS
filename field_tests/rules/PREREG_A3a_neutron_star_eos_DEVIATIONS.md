# DEVIATIONS for PREREG_A3a (written before the rerun)
D1 (crash, 17 Nov): run 1 passed N1 (y_R = 0.289873 vs 0.289868, |Δy| = 4.4e-6) and then crashed in at_mass (brentq: no sign change) before printing any SLy/AP4 number. Cause: the surface event in ns.tov_tidal was set at 1e-6 × pb[0], but pb[0] = K₁·0^Γ = 0 for the lowest crust piece, so the event never fired; the integration ran on with P ≤ 0 (derivatives zeroed) to the 50 km limit, giving wrong surfaces.
Fix: the surface is where the pressure reaches that of ρ = 1e4 g/cm³ on the first crust piece (P_s = K₁ (1e4)^Γ₁ ≈ 1.4e15 dyn/cm², negligible mass above it); no other change. N1 is unaffected (its polytrope has its own pb = 0 and will now stop at ρ = 1e4 g/cm³ of the same rule, which for ρ_c = 1e10 is 1e-6 of the centre — the rerun reports N1 again). Single rerun; verdict from it.
