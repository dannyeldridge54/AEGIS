# PREREG D2077: branch B (accept mirage). Can the 3.5–8 TeV bino LSP avoid overclosure with no new knob? Locked before computing.
**Referee pre-check:**
- A thermal bino freezes out if T_R ≫ m_B̃/20. Pure-bino annihilation is weak, so Ω h² ≫ 0.12 for m_B̃ ≳ 1 TeV (standard).
- v4 has T_R = 3.7e8 GeV.
- KKLT modulus mass m_T ≈ 2x·m₃/₂.

**Rule:**
- **PASS** only if a mechanism **already in v4** (no new coupling) removes the bino. Candidates: T_R < m_B̃/20 (no thermal production), or modulus/dilution without a moduli-induced LSP excess.
- R-parity violation adds a new coupling, so it counts as **FIT**.
