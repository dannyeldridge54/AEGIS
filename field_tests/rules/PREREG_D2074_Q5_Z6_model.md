# PREREG D2074: Q5, a published 3-family brane model on T⁶/Z₆-II or Z₆′ with its tadpole budget. Locked before reading.
**Rule:**
- **PASS** if a cited model gives explicit stacks (gauge groups, multiplicities), a 3-generation chiral spectrum and the RR tadpole numbers, and if it allows (or leaves room for) a large hidden stack such as v4's dark SU(12) = 2 × 6.
- **PARTIAL** if a model exists but has no room for a hidden SU(12), or the tadpole numbers are not stated.
- **FAIL** if none is found.
