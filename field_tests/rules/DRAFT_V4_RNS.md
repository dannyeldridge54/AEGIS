## Added rules
1. **Parameter-free relation.** Q8 implies r = 3(1 − n_s)², whatever N. When r and n_s are both measured (detection of
   r, not an upper limit), the relation is tested in the joint (n_s, r) posterior: outside the 3σ region → **EXCLUDED**
   for any N; inside the 2σ region → **CONSISTENT**; between → **TENSION**.
2. **n_s alone.** N = 50–60 gives n_s = 0.960–0.967. A new n_s (Simons Observatory, or SO + Planck + ACT) with
   n_s − 0.967 > 3σ → **EXCLUDED for N ≤ 60** (the escape N ≥ 62.5 needs a stiffer-than-radiation reheating and is
   reported as the only way out, not adopted).
3. **Which n_s.** The Locked Twist's own fits put n_s at 0.9807 / 0.9811 / 0.9809 (P+ / Dovekie / Union3, stored
   `edelockP*`), above every Q8 value: early dark energy raises n_s. The primary n_s is the one fitted **inside the
   Locked Twist** on the new data; the ΛCDM n_s is reported beside it. On today's stored fits this is already a
   TENSION (0.981 vs ≤ 0.967), on record before any new data.
