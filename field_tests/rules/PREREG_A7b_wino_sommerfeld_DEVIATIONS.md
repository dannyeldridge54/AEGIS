# DEVIATIONS for PREREG_A7b (written before the rerun)
D1 (method error in the B1 CHECK routine only, 17 Nov): run 1 (kept as field_tests/results/janus_astro_a7b_run1.txt) failed B1 by 0.25–2.5%, growing with α/v. Cause: coulomb_single reads the asymptotic amplitude at finite R as hypot(u, u'/k_loc) with the local wavenumber k_loc, but in the WKB regime the amplitude scales as 1/√k(r), so the amplitude at infinity is A_R √(k_loc/k). The missing factor is √(1 + α/(E R)) ≈ 1 + α/(400 v) at R = 400/k, i.e. |s|² low... high by 1 + α/(200 v): 0.5%–5% predicted pattern (observed 0.25%–2.5%, the same α/v scaling; the remaining factor 2 is the ratio of the |s|² vs amplitude exponent, consistent).
Fix: multiply the extracted amplitude by √(k_loc/k) in coulomb_single (the check routine). The wino solver wino_s is unchanged (its open channel has no long-range potential, so it never used this extraction); B2, B3 and the application numbers of run 1 are therefore unaffected and are not rerun for a different answer.
Rerun: the full locked script once; the verdict is read from the rerun. Tolerances unchanged.
