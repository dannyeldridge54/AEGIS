# PREREG_EVIDENCE_ATLAS — how evidence is counted (locked 20 Nov 2026, 06:12 CT, before building)
Danny 06:09–06:10 CT: "fully map out … a table for each toolkit … pile the evidence"; "Test them all. Let's fully test our theory."
1. One row per quantity, generated by code from the live toolkits and the engine (tools/evidence/atlas.py); no row is typed by hand unless it quotes a locked D-note result with its number and source.
2. Every row carries a LABEL: P prediction (could fail) · F fitted to data · A assumed input · S standard physics, not a Weave test · G open (no data or no mechanism yet).
3. STATUS per row: pass |pull| < 2 or limit met; tension 2–3; fail ≥ 3 or limit broken; open (nothing to compare).
4. The headline "evidence" count uses ONLY P rows. F, A and S rows are listed but never counted as support. Fails and tensions are shown with the same prominence as passes.
5. Overlapping data sets (e.g. the CMB n_s sets) are listed per set but the headline uses the newest combined set only, so one measurement is not counted many times.
6. Known failures stay in: lithium-7 (D1640), the dark-matter coupling not detected (D1725), w0wa ahead of the thread, exact TM2 excluded (D1652).
7. Every regeneration records code version and time (provenance); the atlas is rebuilt by CI-safe code with no network access.
