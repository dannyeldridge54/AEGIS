# DECISION RULE D841: status of the τ = i variant
Written and committed BEFORE applying it, 2026-11-16. Uses only existing results (D840 table); no new data or computation.
Categories:
- RETIRE if (R1) any τ = i FROZEN prediction is contradicted by data at ≥ 2σ (current published bounds), or (R2) the variant is internally inconsistent (a computed instability of its vacuum, a tadpole/anomaly failure, or a frozen number that the model cannot produce in exact MS).
- KEEP AS CONDITIONAL VARIANT if neither R1 nor R2 holds but at least one of: (C1) its defining parameter (ε) has no derived source, (C2) its viable parameter window is narrower than its own error budget ×3, (C3) it needs an extra structural condition not shared by the main (ρ) model. Each condition met is listed explicitly in the paper's Limitations.
- KEEP (equal standing) if none of R1, R2, C1–C3 hold.
Motivation-only items (which vacuum loop sums prefer, aesthetic arguments) do NOT enter the rule.
The frozen τ = i predictions never change under any outcome; RETIRE would only stop new work on the variant and mark it retired in the paper.
