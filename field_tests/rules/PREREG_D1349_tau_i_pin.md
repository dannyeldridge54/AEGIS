# PREREG D1349 — what pins the axion at τ = i? (written 18 Nov 2026 before computing)
Context: D1280 — τ = i is a saddle of SERAPIS-E's potential V = P_E(1 + C Ê), P_E = Ê/(Ê+1), Ê = E(τ,2) − E(ρ,2) (E = E_paper, BHK convention), unstable along x = Re τ. D1344 set vac_i = assumed.
Claim to test [derived]: a periodic axion term ΔV = A·V0·(1 − cos 2πx) vanishes with its first x-derivative on x = 0, so it leaves the whole x = 0 trajectory (background, N*, n_s, r, α_s) exactly unchanged; it only adds ∂²ₓΔV = 4π² A V0 at x = 0. τ = i (and the x = 0 path) is stable iff A ≥ A_min = max_y [−∂²ₓV(0, y)]/(4π² V0) over the path.
Computation: C = 1.25e-6 (string benchmark). ∂²ₓV at x = 0 by central differences (h = 1e-4, checked against h = 2e-4 to 1 %) for y ∈ {1, 1.05, 1.1, 1.25, 1.5, 2, 3, 5, 8, 12}; E_paper from tools/serapis_calc/eisenstein (Fourier). Also ∂²_y V at y = 1 (must be > 0 for τ = i to be a minimum along y as well; if it is ≤ 0, the pin alone is not enough and that is reported).
Reported: ∂²ₓV(0,y)/V0 along the path, A_min, where the maximum sits, and the sign of ∂²_y V at τ = i. Interpretation limits: A is a parameter, not derived; this says how big an explicit-CP/instanton-type term must be, not that one exists in the compactification.
PASS/FAIL of the claim: the identity ΔV = ∂ₓΔV = 0 on x = 0 is checked numerically to 1e-12; the stability condition is reported as computed. Single run.
