# PREREG D2054: Q1, can a warped-throat D3 visible sector keep pure AMSB gauginos in KKLT? Locked before reading.
**Referee pre-check (textbook formula):** M_{1/2} = F^i ∂_i f_vis / (2 Re f_vis) + AMSB (b_a g_a²/16π²)·m₃/₂.
- For D3-branes, f_vis = S, so the modulus piece is F^S/(2 Re S). Sequestering also needs the visible Kähler metric to be free of F^T couplings (conformal sequestering, Luty–Sundrum).

**Rule** (by what the literature states):
- **PASS(Q1)** if a KKLT-type construction with visible D3s at the tip of a warped throat is shown to give gaugino and scalar soft terms dominated by anomaly mediation, with F^S suppressed (ISD flux).
- **FAIL** if the literature shows sequestering is spoiled at O(m₃/₂/x) or by bulk-field mediation at a level above the D2039 bound (sq ≤ 1.2e-3).
- **UNDETERMINED** if it is disputed with no conclusion.

**Cost if PASS:** f_vis = S changes the gauge chain (cube axis V). That cost is recorded, not solved.
