- With the no-scale volume K = −3 ln(T+T̄) and K_XX̄ = 1 − 2βt: V_inf(t) = V₀ (2t)⁻³ / (1 − 2βt).
- Mapping assumption: X stands for the S-sector inflation F-term.

**Compute:**
- the inflationary minimum t* (dV/dt = 0) as a function of β;
- the β that puts t* at v4's late value t = 20.15 (no overshoot);
- m_T² = V''(t*) / (2K_TT̄) with K_TT̄ = 3/(2t)², against H² = V/3;
- whether K_XX̄ > 0 at t*.

**Verdict:**
- **PASS** if the required β is natural (0.1–10), K_XX̄ > 0 and m_T²/H² ≥ 10.
- **FIT** if a solution exists only for unnatural β.
- **FAIL** if none exists.
