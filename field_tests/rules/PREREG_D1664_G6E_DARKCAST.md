# PREREG_D1664_G6E_DARKCAST — the P-M dark photon strip from published limit tables (Janus genesis G6e; locked 2026-11-19 ~23:58Z before any number)
Download (Danny's OK, 17:37 CT "Ok" / "Dl"): DarkCast limit tables (Ilten, Soreq, Williams, Xue, arXiv:1801.04847; official home gitlab.com/darkcast/releases is blocked here) from the GitHub mirror github.com/micha-a-schmidt/darkcast, commit db9a0f66ec99946930dc263a042ec531c9576068 (dated 2022-08-12). Treated as data only (no code from it is executed); tables are not copied into this repo (GPL-2); the script reads them from the download folder given as an argument.
Which limits (decided from each limit's own metadata, read as text): model "dark_photon" AND a visible decay (e_e, mu_mu, pi+_pi-). Excluded: invisible searches (BaBar 2017, Belle II 2019, NA62, NA64 invisible, LEP), the g−2 files (decay "none"), and ATLAS/CMS Higgs-branching files (model-dependent). Visible limits apply because m_A' < m_DM = 5.03 GeV < 2m_DM, so A' → χχ̄ is closed (D1657).
Format: mass (GeV), ε lower [, ε upper]. Two columns ⇒ excluded for lower < ε < upper; one column ⇒ excluded for ε > lower. Log-linear interpolation inside each table's mass range; nothing outside it.
Also applied: D1657 BBN floor (ε > ε_min(m) for τ < 1 s, log-log interpolation of D1657's json) and the SN1987A band 1e-10 – 1e-6 for m ≤ 0.1 GeV (1612.07295, 1611.03864; approximate, as in D1659).
Grid: 400 log-spaced masses in [0.02, 5.03] GeV; ε grid 2000 log-spaced in [1e-13, 1e-2].
Outputs: per mass the allowed ε intervals; the lowest mass with an allowed interval ≥ 1 decade wide (the window's lower edge, D1659 said ~0.3 GeV, approximate); the upper beam-dump edge ε_max(m) at 0.3, 1, 3 GeV; whether any mass in 0.3–5 GeV is fully closed.
Reading (locked): D1659's window is CONFIRMED if the DarkCast-based lower edge lies within a factor 3 of 0.3 GeV and every mass in [1, 5] GeV keeps ≥ 1 decade open; SHARPENED if the edge moves by more than ×3 but the window stays open; CLOSED if no mass keeps ≥ 1 decade. Caveat stated now: tables end in 2022 (newer NA64/LHCb/Belle II results not included) — later limits can only shrink the window.
