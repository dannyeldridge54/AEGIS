# DEVIATIONS — PREREG_GENESIS_BBN2 (written before any rerun; no Y_p had been seen)
D1: crash in the dense-output step. Diagnosis (rates printed only, no abundances): the phase-space integrand used x·√(x²−1) on the x ≤ −1 branch (the positron processes). That makes the branch NEGATIVE, so it cancels the electron branch. Result: λ_np(1 MeV) = 0.0086 s⁻¹ (the standard value is ≈ 1–2 s⁻¹) and λ_pn < 0. The standard form uses the energy magnitude |x|. Fix: x → |x| in the prefactor. This is a coding error against the locked method, not a change of method. Nothing else changed.
D2: the solver fails at the first step ("step size less than spacing"); no abundances were produced. Cause: the rates were cached on log T rounded to 10⁻³, a step function the stiff BDF solver cannot handle. Fix: tabulate the Born rates on the background grid once and interpolate log λ smoothly in t. A numerical implementation fix; physics and pass rules unchanged.
D3: the solver still fails at the first step (no abundances produced). Cause: photodissociation at T = 10 MeV runs at ~10¹⁷ s⁻¹, so the needed step is below floating-point spacing at t ≈ 0.007 s. Fix (the standard quasi-equilibrium treatment): above T_sw = 0.2 MeV, deuterium sits at its detailed-balance (Saha) value, Y_d = n_b⟨σv⟩Y_nY_p/λ_γ; only n ↔ p is integrated. Below T_sw the full network runs, starting from that value. No physics or pass rule changed (detailed balance is already part of the locked method).
