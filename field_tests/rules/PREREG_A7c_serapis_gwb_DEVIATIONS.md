# DEVIATIONS for PREREG_A7c (written before the rerun)
D1 (crash, no results produced, 17 Nov): the first run stopped in C1 with "mode not superhorizon inside the background": a pure-radiation history with inflation ending at N = 0 has k_end = k_R, so modes k ≥ 1e-3 k_R never start 1e3 outside the horizon. The C1 test history was mis-specified, not the solver.
Fix: C1 uses a radiation phase extended back by a factor 1e12 in density (History([(1/3, ln 1e12)]), k_end = 1e3 k_R), so every C1 mode starts 1e3 outside the horizon during inflation. In the application, route B is evaluated only for k ≤ 1e-3 k_end (superhorizon start inside inflation); higher frequencies are reported as "n/a (within 3 decades of f_end)". No other change; the full locked script is run once more.
D2 (second crash, partial output only, 17 Nov): the rerun passed C1 (T² = 1.000000 ×5) and the τ = i matter band (slope −2.0000, route A/B dlog 0.205), then stopped at the SERAPIS-E ρ matter band: its centre k_c ≈ 173 k_R lies within 1e3 of k_end ≈ 3e4 k_R, so the start condition "k/aH = 1e-3 during inflation" cannot be met. Cause: the start rule in route B (gwb.History.T2) required each mode to start 1e3 outside the horizon DURING INFLATION, which is not needed: a superhorizon tensor mode is constant (growing mode) in every era.
Fix (solver change, stated before the rerun): T2 starts each mode at the LAST time before re-entry when k/aH = 1e-3 (on the post-inflation branch if the mode was that far outside the horizon at the end of inflation), else at the end of inflation with h = 1, h' = 0, and flags the start value k/k_end (error O((k/k_end)²)). The application still reports n/a within 3 decades of f_end (D1). Tolerances unchanged. Third and last run; if it fails again the verdict is NOT VALIDATED as it stands.
