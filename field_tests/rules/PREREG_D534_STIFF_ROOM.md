# PREREG D534 — is there room for a stiff (kination-like) reheating phase in SERAPIS-1? (locked 2026-11-14 22:22 CT before computing)
Crossover vacuum: V = (m²/2)φ²[1 + (φ/φc)⁴] (quadratic near the minimum, |φ|⁶ further out). A stiff phase (w = ½) needs V_end to be dominated by the sextic term, i.e. (m²/2)φ_end² < V_end.
Inputs: V* from r = 0.0012, A_s = 2.1e-9: V* = (3π²/2)A_s r M_P⁴; V_end = 0.1 V*; φ_end = 1 M_P (canonical distance from the minimum at the end of inflation; order one).
m: (a) SERAPIS-1 value 4.0e13 GeV (D517); (b) minimum mass for the inflaton to reheat gravitationally to T_RH = 5.5e10 GeV (D523), m_min = (T_RH² M_P)^{1/3}.
PASS (stiff room exists) if (m²/2)φ_end² < V_end for m = m_min; then report the maximal N* gain = (1/9) ln(ρ_end/ρ_c), ρ_c = m²φc², with φc chosen so the sextic dominates at φ_end. FAIL otherwise (trade-off is sharp: Kairos N* stays 52–55.6).
