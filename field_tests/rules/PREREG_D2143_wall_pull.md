# PREREG D2143: "wall here, test each node in each direction" (Danny 19:30). Pull every tie and look for a clock shift ("thrust")
Locked before computing. Danny's postulate: a negative-space wall that ties back to "here" does so by stretching time, so pulling it should move the cosmic clock.

## Two clocks
- **Early clock N\*:** the number of e-folds at horizon exit. It sets when the CMB scales left the horizon.
- **Late clock t₀:** the age of the universe, computed with the calibrated weave_engine (D2134 b = 0 Dovekie best fit, with H0 refitted by holding Ω_m h² and the thread fixed).

## The pull
Each node with a numeric tie is pulled in **both directions**: the knob × 1.5 and × 1/1.5 (or ± the stated step). We record the clock responses Δ₊ and Δ₋.
- **Response:** (Δ₊ − Δ₋)/2.
- **"Thrust":** the net drift under a symmetric pull, (Δ₊ + Δ₋)/2. It is zero for a linear tie and non-zero when the wall is curved.
- A node with no numeric tie to either clock is reported as **"ties through mass or charge, not time"**.

## Formulas (S = standard, R = record)
- N\* responses:
  - reheating: ΔN\* = ⅓ ln(T_R/T_R0) [R, D1759]
  - dilution: ΔN\* = −⅓ ln D [R, D1766]
  - tensor ratio: r ∝ 1/N\*², so ΔN\* = −(N\*/2) Δln r, with N\* = 2/(1 − n_s) = 68.0 [S, plateau]
- t₀ responses: integrate da/(aH) through the engine background, with the thread start u_i, the coupling b, Σm_ν, ΔN_eff (as extra radiation) and H0 as the knobs [S].

## What counts as Danny's effect
- **"Ties through time":** |response| ≥ 0.01 e-folds or ≥ 1 Myr.
- **"Thrust seen":** |thrust| ≥ 10% of |response|.

This is a sensitivity map, not evidence. No reruns to chase results.
