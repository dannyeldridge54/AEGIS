# AEGIS Field Equation Papers

## Building PDFs

### Option 1: Install MiKTeX (Windows)
```
winget install MiKTeX.MiKTeX
# Then restart terminal and run:
pdflatex paper1-aegis-methodology.tex
bibtex paper1-aegis-methodology
pdflatex paper1-aegis-methodology.tex
pdflatex paper1-aegis-methodology.tex

pdflatex paper2-torsion-ufe.tex
bibtex paper2-torsion-ufe
pdflatex paper2-torsion-ufe.tex
pdflatex paper2-torsion-ufe.tex
```

### Option 2: Overleaf
1. Upload all `.tex`, `.bib` files and the `figures/` folder to a new Overleaf project
2. Set `paper1-aegis-methodology.tex` or `paper2-torsion-ufe.tex` as main document
3. Compile

### Option 3: Docker
```
docker run --rm -v "$(pwd):/work" -w /work texlive/texlive pdflatex paper1-aegis-methodology.tex
```

## Figures
Generated by `python generate-figures.py` from the repo root:
- `figures/scoreboard.pdf` — 15-task optimization scoreboard
- `figures/h0_tension.pdf` — H₀ measurement comparison
- `figures/posteriors.pdf` — MCMC parameter posteriors
- `figures/blind_test.pdf` — Blind BAO prediction residuals

## Regenerating Figures
```
cd ..
python generate-figures.py
```
Requires: `pip install matplotlib numpy`

