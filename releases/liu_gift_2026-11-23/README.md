**Start here:** `Liu_lab_data_packet.pdf` (3 pages: what to plug into your own model, in your notation).

| Folder | What it is |
|---|---|
| `data/` | CSV tables in Hz and ms: period vs q (c₂ = 23.7 Hz), β order parameter, U-state time series (N = 6–80), tuned small-N settings |
| `engine/` | **Spindle**, the Python engine (exact spin-1 single-mode with drive, mean field, Bose–Hubbard chain) and its validation checks |
| `tool/Spindle.html` | Interactive version; opens in any browser |
| `weave/` | Background: *The Weave* preprint (DOI 10.5281/zenodo.24453858), supplement, engine, unified field equation and geometry maps |
